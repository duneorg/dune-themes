# Dune Minimal demo site

Local preview of `@dune/theme-dune-minimal` using shared blog fixture content.

```bash
# From repo root
deno task demo dune-minimal
deno task demo:validate dune-minimal
```

Open http://localhost:8825 after `demo` starts.

**Deploy target:** https://themes.getdune.org/dune-minimal

`content/` is generated by `deno task demo:link dune-minimal` — copied from
`demos/_shared/blog/` (re-run `demo:link` after editing the source; it
isn't live-linked). Theme is symlinked from `packages/theme-dune-minimal/`.
