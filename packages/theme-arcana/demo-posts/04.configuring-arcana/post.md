## `banner_title` / `show_banner`

Home shows `#banner` when `show_banner` is on. This demo’s headline is
**“Arcana for Dune”**. Disable the banner only when you’re testing a
bannerless shell — side-by-side QA against upstream wants it on.

Empty title falls back to the site title. Seed a short line before
marketplace screenshots.

## `tagline`

Used as the logo/supporting line in Arcana’s header chrome. Seeded as
**“Corporate landing for Dune”** so the first viewport isn’t empty
description text.

## `show_html5up_credit` / `footer_text`

Credit on; **Arcana Demo** in the copyright slot. Still one upstream
design — no dark mode, no scheme presets. Flip credit off only with a
separate Pixelarity license; the gate should hide every credit surface
together.
