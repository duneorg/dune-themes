  mode or color-scheme presets in this port.
---

Upstream [Tessellate](https://html5up.net/tessellate) stacks full-bleed dark
sections: `#header` hero, `#first` three-icon feature row, `#second` six-tile
gallery beside copy, `#third` featured-image band, `#fourth` contact-style CTA,
then `#footer`. This Dune port keeps that scroll shell but repoints every
Explore / Blog / About / gallery tile at Blog, Search, Archives, or About so
nothing dies on a `#` stub.
