Portfolio themes need leaves that look like projects, not only install
READMEs. This entry fills the home “Get Started” path with a cover the
stylesheet already styles, plus a short body so the post template isn’t
a title-only stub.

Lighting notes for the fictional brief: warm key, cool fill, and a long
shadow that reads on Photon’s light ground. Swap the cover path when you
vendor your own frames — keep the `/themes/photon/static/…` prefix so
`basePath` demos resolve.
