Phantom's header is a small logo mark plus a single "Menu" trigger — everything
else lives behind the slide-out `#menu` panel. Below the fold, posts render as
alternating tile sizes (`style1` through `style6`, cycling every six items) so
the grid never feels like a flat repeating pattern.

Open the menu on a narrow viewport first: that's the fidelity check this demo
exists for. Then scroll the tiles and compare their rhythm with
[html5up.net/phantom](https://html5up.net/phantom).
