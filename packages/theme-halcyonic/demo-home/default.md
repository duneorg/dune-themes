  Halcyonic adapted from HTML5 UP for Dune — two-column banner over a four-up

  presets in this port.
---

Upstream [Halcyonic](https://html5up.net/halcyonic) opens inside `#header`
with a logo-and-nav row, then a two-column `#banner` (copy plus `button-large`
beside a bordered feature image). Below that, `#features` lays out four equal
columns — thumbnail, heading, short paragraph. This Dune port keeps that rhythm
but repoints every feature card and the banner CTA at a real route — Blog,
About, Archives, and the upstream design page — so the demo never dead-ends on
a static HTML5 UP file.
