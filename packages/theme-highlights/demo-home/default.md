Upstream [Highlights](https://html5up.net/highlights) is a single-page scroll:
a tall `#header` with dual actions (Begin / Read the Blog), then `#one` /
`#two` / `#three` special sections each pairing a primary image with copy and a
`goto-next` scrolly control, ending on `#footer`. This Dune port keeps that
shell but points Begin at `#one`, Read the Blog at Blog, and the icons grid at
Blog, Search, Archives, and About.
