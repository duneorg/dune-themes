  Landed adapted from HTML5 UP for Dune — sticky header, full-viewport banner,
  alternating spotlights, feature grid, and closing CTA. Single upstream design;
  no dark mode or color-scheme presets in this port.
---

Upstream [Landed](https://html5up.net/landed) is scroll-driven: sticky
`#header`, a full-viewport `#banner`, then alternating `spotlight` sections
(`#one` / `#two` / `#three`) joined by `.scrolly` “Next” anchors, a `#four`
icon grid, and a `#five` closing CTA. This Dune port keeps that sequence but
repoints every button and spotlight action at a real route — Blog, Search,
Archives, About — so QA never lands on a dead HTML5 UP page file.
