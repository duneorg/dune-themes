  Ethereal adapted from HTML5 UP for Dune — panel.banner plus spotlight panels and a

  this port.
---

Upstream [Ethereal](https://html5up.net/ethereal) scrolls as a stack of `.panel` sections
inside `#wrapper`: a `panel.banner.right` intro, spotlight panels with filtered images, and
a `panel.color1` icon grid. This Dune port keeps that panel rhythm but repoints every
grid icon and spotlight CTA at a real route — Blog, Search, Archives, About — so the
targets resolve instead of dead-ending on anchors.
