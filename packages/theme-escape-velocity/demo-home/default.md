  Escape Velocity adapted from HTML5 UP for Dune — #logo/#nav header over intro, main
  features, and highlight cards. Single upstream design; no dark mode or color-scheme
  presets in this port.
---

Upstream [Escape Velocity](https://html5up.net/escape-velocity) opens on `#header.wrapper`
with `#logo` and `#nav`, then stacks `#intro`, `#main` (feature list), `#highlights`, and
`#footer` as titled wrapper sections. This Dune port keeps that sectioned rhythm but
repoints every highlight card and action button at a real route — Blog, Search, Archives,
About — so the CTAs resolve instead of dead-ending on anchors.
