The header above this text reads **“Fractal”** and **“A phone-first
portfolio for Dune demos”** — `header_title` and `header_subtitle` in
`demo-config.json`, both falling back to the site title and description
when left empty. Next to them, the phone mockup image is `phone_image`,
pointed here at the vendored `static/html5up/images/screen.jpg` instead of
a blank frame; a real deployment would swap in a screenshot of the actual
site or app being showcased.

The **Get Started** button under the header is the only first-viewport
call to action, landing on `/blog`. Below the fold, three `spotlight`
panels repeat that pattern in miniature — Projects, Search, and Archives,
each with its own image and a "Learn More" button pointed at a real Dune
route, followed by an icon row duplicating those same four destinations
for a quick second pass.

That two-tier layout (hero, then spotlight/icon grid) is Fractal's whole
first viewport; everything else — the project write-ups, the install and
config notes — lives one click away on [Blog](/blog).
