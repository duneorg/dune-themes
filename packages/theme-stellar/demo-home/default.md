Upstream [Stellar](https://html5up.net/stellar) is a multipurpose landing:
`#header.alt` with logo mark + title, sticky `#nav`, an `#intro` spotlight, a
`#first` icon features row, a `#second` statistics band, a `#cta` dual-button
close, and a two-column `#footer`. This Dune port keeps that structure and
points every Learn More / Get Started / About action at Blog or About, with
Search and Archives on the icon features and footer Explore row.
