  Directive adapted from HTML5 UP for Dune — paper-plane #header over alternating
  feature bands and a closing footer CTA. Single upstream design; no dark mode or
  color-scheme presets in this port.
---

Upstream [Directive](https://html5up.net/directive) opens on a tall `#header` with a
paper-plane icon, then drops into `#main` where left/right `section.feature` bands
carry image-and-copy pairs before a `footer.major` CTA. This Dune port keeps that
rhythm but repoints every feature heading and button at a real route — Blog, Search,
Archives, About — so the CTAs resolve instead of dead-ending on anchors.
