Upstream [Strata](https://html5up.net/strata) reads like a personal studio page: a round
avatar sits in the header next to the site name and `tagline`, everything else scrolls
under `#one` and `#two`. This Dune port keeps `#one` as the intro copy from this page and
turns `#two` into a live thumbnail grid — Blog, Search, Archives, About, plus two named
posts — so every tile resolves to a real route instead of a mockup link.
