  Twenty adapted from HTML5 UP for Dune — a full landing banner over stacked feature,
  icon, and image sections. Single upstream design; no dark mode or color-scheme presets
  in this port.
---

Upstream [Twenty](https://html5up.net/twenty) is a full landing page: `#banner` up top with
`banner_title`, then alternating `wrapper.style1/2/3` sections for feature copy, icon
lists, and featured images, closed by a CTA and an icon footer. This Dune port keeps every
section but repoints its links — the feature copy talks about Dune's blog, search, and
archives instead of upstream's generic marketing copy, and the featured images link to
real routes instead of anchors.
