  ZeroFour adapted from HTML5 UP for Dune — header logo, nav, and strong banner

Upstream [ZeroFour](https://html5up.net/zerofour) leads with
`#header-wrapper`: site logo, `#nav`, and a bold `#banner` that pairs a strong
tagline with a large Explore button. This Dune port keeps that minimal shell —
no feature grid below the banner, only the content panel — and points Explore
at Blog so the first CTA is a real collection. Nav also reaches Search,
Archives, and About.
