## `header_title` / `header_subtitle`

Landing copy. This demo sets **Dimension** and a subtitle that tells
visitors to open a nav item. Empty title falls back to the site title;
empty subtitle falls back to the site description — seed both before
screenshots so the gem header isn’t blank.

## `logo_icon`

Font Awesome class for the logo circle (default `fa-gem`). Change it when
the brand isn’t a gem — keep the `fa-` prefix the stylesheet expects.

## `show_html5up_credit` / `footer_text`

Credit on; **Dimension Demo** as copyright name. Still one upstream
design — no dark mode, no color-scheme presets. Flip credit off only with
a separate Pixelarity license.
