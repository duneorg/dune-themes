  Solid State adapted from HTML5 UP for Dune — a gem-icon banner over four alternating
  spotlight sections and a closing feature grid. Single upstream design; no dark mode or
  color-scheme presets in this port.
---

Upstream [Solid State](https://html5up.net/solid-state) opens on a centered `#banner` with a
gem icon, then alternates image-and-copy `spotlight` sections (`#one`/`#two`/`#three`)
before a `#four` feature grid and a `#footer` CTA. This Dune port keeps that rhythm but
repoints every spotlight and feature card at a real route — Blog, Search, Archives, About —
so the CTA links resolve instead of dead-ending on anchors.
