  Multiverse adapted from HTML5 UP for Dune — fullscreen thumb grid with a
  footer panel of explore icons. Single upstream design; no dark mode or
  color-scheme presets in this port.
---

Upstream [Multiverse](https://html5up.net/multiverse) fills the viewport with
a `#main` grid of `article.thumb` tiles — full image, thumbnail, title, and
caption — then opens a `#footer.panel` that splits site copy from a get-started
column. This Dune port keeps that gallery shell but wires the footer icons and
buttons to real routes — Blog, Search, Archives, About — so the demo never
dead-ends on a static HTML5 UP page file.
