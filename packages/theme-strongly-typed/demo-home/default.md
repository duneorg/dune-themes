Upstream [Strongly Typed](https://html5up.net/strongly-typed) leads with
typography: `#header` centers a logo, short tagline, and boxed nav; on the
homepage a `#banner` strip carries one intro line before `#main` opens the
content columns. This Dune port keeps that rhythm but points nav and post links
at real fixtures — Blog, Search, Archives, About — so the demo never dead-ends
on a static HTML5 UP page file.
