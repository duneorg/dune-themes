A faithful-adjacent port of [HTML5 UP Parallelism](https://html5up.net/parallelism)
for Dune. The intro tile sits first in the `#main` row, followed by eight
masonry thumbs (spanning 1–3 columns, staggered fade-in delays) that link out
to Blog, Search, Archives, About, and three sample project posts. Desktop
scrolls the row horizontally with the mouse wheel, arrow keys, or the
invisible edge zones; under 736px it falls back to plain `overflow-x` touch
scrolling.

The footer under the scroll area reads "This is **Parallelism** —
`home_subtitle`, a responsive portfolio theme by HTML5 UP adapted for Dune,"
then repeats the nav as icon links and closes with the copyright line. Compare
the column widths and scroll feel against
[html5up.net/parallelism](https://html5up.net/parallelism).
