Upstream [TXT](https://html5up.net/txt) is deliberately quiet: a slim `#header` with the
site name and `tagline`, a scrolly `#banner`, then a boxed intro over four feature tiles.
This Dune port keeps that rhythm on `/` and `/home` — the highlighted box carries this
page's copy, and the feature row below points at Blog, Search, Archives, and About instead
of upstream's generic icon links.
